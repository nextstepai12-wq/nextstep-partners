# شبكة شركاء NextStep AI

منظومة متكاملة لاستقبال طلبات الشراكة من الشركات والفرق والمؤسسات وإدارتها، مبنية على **GitHub Pages** (واجهات ثابتة) و**Supabase** (قاعدة بيانات + مصادقة)، بهوية NextStep AI البصرية وعناصر ثلاثية الأبعاد.

## المكوّنات

| المكوّن | الملف | الوظيفة |
|---|---|---|
| **صفحة الشركاء** (عامة) | `index.html` | تعريف بالمنصة، نموذج تسجيل من 4 خطوات، رمز متابعة، تتبّع الطلب، أسئلة شائعة، قنوات التواصل، بطاقة المؤسس |
| **لوحة الإدارة** (للفريق) | `admin.html` | دخول بالبريد وكلمة المرور، مؤشرات، جدول بفلترة وبحث، تعديل الحالة والملاحظات، تحديد جماعي، تصدير CSV/JSON، سجل نشاط |
| **سياسة الخصوصية** | `privacy.html` | ما نجمعه ولماذا ومن يطّلع وحقوق الشريك |
| **قاعدة البيانات** | `database/*.sql` | الجداول، الدوال والمشغّلات، سياسات الأمان (RLS)، أول مدير، إشعار تيليغرام |
| **حماية متقدمة (اختيارية)** | `supabase/functions/submit-partner` | Cloudflare Turnstile عبر Edge Function |
| **الاختبارات** | `database/tests`, `tests/browser` | اختبارات قاعدة البيانات والمتصفح |
| **التوثيق** | `SETUP.md`, `docs/` | التشغيل والإدارة والأمان وقاموس البيانات |

## كيف يعمل (باختصار)

1. الشريك يملأ النموذج ← يُحفظ الطلب في جدول `partners` (الزائر يملك صلاحية **الإضافة فقط**) ويحصل على رمز متابعة `NS-XXXXXXXX`.
2. مشغّلات قاعدة البيانات توحّد البريد، وتتحقق من رمز المتابعة، وتطبّق حدود المعدّل، وتكتب سجل التدقيق، وترسل إشعار تيليغرام (اختياري).
3. فريقك يدخل `admin.html` ويراجع الطلبات. صلاحية كل شخص تحددها أدوار `owner / admin / viewer` في الجدول `partner_admins`، وتُفرض داخل قاعدة البيانات نفسها.
4. الشريك يتتبّع حالة طلبه من الصفحة العامة (رمز + بريد) دون أن يرى أي بيانات شخصية أو ملاحظات داخلية.

## للبدء
اتبع **[SETUP.md](SETUP.md)** بالترتيب. التوثيق التفصيلي في مجلد [`docs/`](docs).

## ما جرى اختباره وما لم يُختبر
مفصّل في [docs/TESTING.md](docs/TESTING.md). باختصار: اختُبرت قاعدة البيانات على PostgreSQL 16 حقيقي بأدوار Supabase مُحاكاة، واختُبرت الواجهات في متصفح Chromium بخادم وهمي يحاكي Supabase. **لم يُجرَّب** شيء على مشروع Supabase الحقيقي ولا على Telegram وCloudflare وواتساب، فنفّذ «اختبار ما بعد النشر» في SETUP.md.
