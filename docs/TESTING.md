# الاختبارات

## ما الذي اختُبر فعليًا
| المجموعة | العدد | البيئة | الملف |
|---|:--:|---|---|
| **قاعدة البيانات** (RLS، مشغّلات، دوال، حدود، أدوار) | **55** | PostgreSQL 16 حقيقي + أدوار `anon/authenticated` + `auth.uid()` مُحاكاة | `database/tests/run_tests.py` |
| **لوحة الإدارة** (دخول، أدوار، مؤشرات، فلترة، تعديل، جماعي، تصدير، حذف، خمول، تجديد رمز، XSS، جوال) | **64** | Chromium (Playwright) + خادم وهمي يحاكي Supabase | `tests/browser/test_admin.py` |
| **الصفحة العامة** (تسجيل، رمز متابعة، تتبّع بكل الحالات، مكرر، جوال، 3D) | **43** | Chromium + خادم وهمي | `tests/browser/test_public.py` |
| **سكربت الإشعار** | يدوي | PostgreSQL محلي مع دالة وهمية بدل `pg_net` | انظر أدناه |
| **صياغة كل ملفات SQL** | 5/5 | محلّل PostgreSQL (`pglast`) | — |

اختُبرت قاعدة البيانات في مسارين: **ترقية** من الجدول القديم (مع صف قديم) و**تثبيت جديد من الصفر**، وأُعيد تشغيل السكربتات مرتين لإثبات إمكانية إعادة التشغيل.

عروض الشاشات المفحوصة بلا تمدد جانبي: 320 · 340 · 360 · 375 · 390 · 414 · 768 · 1024 · 1366.

### أمثلة على ما تثبته اختبارات قاعدة البيانات
- الزائر يُدخل طلبًا صالحًا فقط، ولا يقرأ ولا يعدّل ولا يحذف، ولا يقرأ `partner_admins` ولا سجل التدقيق.
- لا يستطيع فرض `status=approved` أو كتابة `notes` أو `priority` أو تزوير `reviewed_by`.
- روابط `javascript:` وهواتف بلا مفتاح دولة وبريد غير صالح ونبذة قصيرة: مرفوضة.
- المستخدم المسجّل غير الإداري لا يرى شيئًا ولا يعدّل.
- المشاهد يقرأ فقط. المشرف يعدّل ولا يحذف ولا يرفع صلاحيته ولا يضيف مديرين. المالك يحذف.
- التدقيق يسجّل تغيير الحالة مع بريد المنفّذ، والحذف أيضًا.
- `ref_code` و`consent` لا يتغيّران بعد الإدخال.
- التتبّع لا يعيد شيئًا عند بريد أو رمز خاطئ، ولا يكشف أعمدة شخصية.
- حد الـ3 طلبات/يوم لكل بريد والحد العام 30/10 دقائق يعملان.

### الإشعار (يدوي)
أُجري باستبدال `net.http_post` بدالة وهمية تسجّل الطلب: لا إرسال قبل تعبئة الأسرار؛ الرسالة تحتوي الرمز والجهة والمجال والموقع والمسؤول والبريد والهاتف والاهتمامات؛ فشل الإرسال لا يمنع حفظ الطلب؛ الزائر لا يقرأ `private.partner_secrets`.

## ما **لم** يُختبر (يحتاج منك اختبارًا بعد النشر)
- مشروع Supabase الحقيقي (إعدادات Auth، المفاتيح، الأذونات الافتراضية للمشروع).
- إرسال تيليغرام الفعلي عبر `pg_net`.
- Cloudflare Turnstile والـ Edge Function (اختُبر مسار الواجهة بمحاكاة فقط).
- أجهزة الجوال الحقيقية (الفحص بمحاكاة داخل Chromium) ومتصفحات Safari وFirefox.
- معاينة المشاركة في واتساب/لينكدإن (تعتمد على العنوان النهائي).
- ثقل الأداء مع آلاف الطلبات (اللوحة تحمّل كل الطلبات في المتصفح وتجمّعها هناك؛ مناسبة لمئات إلى بضعة آلاف).

## إعادة التشغيل
```bash
# قاعدة البيانات (يتطلب PostgreSQL محليًا وpsycopg2؛ شغّل الأوامر بمستخدم postgres)
createdb nsdb && psql -d nsdb -f database/tests/00_local_stubs.sql
psql -d nsdb -f database/01_schema.sql -f database/02_functions_triggers.sql -f database/03_security_rls.sql
python3 database/tests/run_tests.py nsdb

# المتصفح (يتطلب playwright + chromium)
python3 -m http.server 8765 &           # من جذر المشروع
python3 tests/browser/test_admin.py
python3 tests/browser/test_public.py
```
> اختبارات المتصفح تستبدل Supabase بخادم وهمي (`tests/browser/fake.py`)، فلا تتصل بأي مشروع حقيقي.
